# Tomlify/JSONify
## Инструмент, который преобразует файл content.json в файл content.toml

По сути, этот инструмент предназначен для модмейкеров Null's Brawl, которые хотят преобразовать свой content.json в файл content.toml.

Я знаю, что это бесполезно и зачем это вам нужно, но кто этого хочет? 
(я, просто потому что мне скучно).

## Как это использовать?
- Загрузите tomlifier.exe из [releases](https://github.com/ARS7236/json-toml-converter-nb/releases)
  - Рекомендуется после загрузки этого инструмента поместить его туда, где находится ваш content.json, или перетащить ваш content.json туда, где находится этот инструмент.
- Затем используйте его следующим образом:
```
tomlifier.exe <content.json> <content.toml>
```
Просто, не правда ли?

## Сборка
Если вы хотите собрать это со своего ПК, то
в репозитории уже есть готовый файл "build.py"
И просто загрузите два файла из репозитория:
- tomlify.py
- build.py

<i>(я хочу вас предупредить, что при загрузке этих файлов не отправляйте их отдельно! они должны находиться в одной папке! потому что если они не в одной папке, файл build.py выдаст вам ошибку, что tomlify.py отсутствует, он не сможет найти этот файл или если tomlify был переименован!)</i>

затем, когда вы загрузили файлы, откройте cmd и введите:
```
py build.py
```
или просто дважды щелкните на build.py, и он создаст инструмент (exe будет в папке dist после завершения). или то же самое через cmd, просто введите:
```
build.py
```
и готово со сборкой! (^_^)
